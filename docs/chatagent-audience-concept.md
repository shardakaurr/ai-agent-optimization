## CLI and Web UI Interaction Model

The documentation agents can be interacted with through two main interfaces:

### CLI Interaction
A command-line interface allows structured execution of agent tasks.
Example commands could include:
- generate-docs
- validate-docs
- refine-docs

This enables repeatable workflows and integration into developer environments.

### Web UI Interaction
A web-based interface provides a human-friendly way to interact with the agents.

Capabilities include:
- Entering prompts
- Viewing generated documentation
- Seeing validation scores and feedback

In this project, the core agent workflow is already defined.
CLI and Web UI represent the primary interaction surfaces for using the system.

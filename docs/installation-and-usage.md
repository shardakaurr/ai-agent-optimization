# Installation and Usage Instructions

## Overview

This document explains how to set up and use the project locally using GitHub and VS Code.
The system is documentation-driven and does not require building or running an application.

---

## Prerequisites

* GitHub account
* Git installed on your system
* Visual Studio Code
* GitHub Copilot enabled in VS Code

---

## Installation Steps

1. Clone the repository:

```bash
git clone https://github.com/shardakaurr/ai-agent-optimization.git
```

2. Open the project in VS Code:

```bash
code ai-agent-optimization
```

3. Ensure GitHub Copilot Chat is enabled in VS Code.

---

## How to Use the System

1. Open documentation tasks in the `experiments/` folder.
2. Use GitHub Copilot Chat as different agents (authoring, validation, refinement).
3. Apply the rubric in `docs/rubric.md` to evaluate outputs.
4. Record evaluation results in `results/rubric-run.md`.

---

## Summary

No application execution is required. The project runs through structured documentation workflows and agent-based evaluation using GitHub Copilot Chat.

# Content Specification

## Purpose

This specification defines the required structure and constraints for
AI-generated documentation produced in this project.

It ensures consistency, completeness, and validation readiness.

---

## Target Audience

* Beginner developers
* Students new to GitHub and version control

The content should assume minimal prior knowledge.

---

## Required Output Format

All documentation must follow this exact section order:

1. Title
2. Overview
3. Prerequisites
4. Step-by-step Instructions
5. Validation Checklist
6. Summary

---

## Writing Guidelines

* Use simple, clear language
* Keep sentences short
* Use numbered steps where applicable
* Avoid unnecessary jargon

---

## Code and Commands

* Commands must be shown using fenced code blocks
* Only verified and standard Git commands are allowed
* Do not invent commands or APIs

---

## Security Guidelines

* Do not include passwords or secrets
* Authentication steps should be described conceptually
* Use placeholders where needed

---

## Validation Requirements

Each document must:

* Include a validation checklist
* Allow readers to verify successful completion
* Be suitable for rubric-based evaluation

---

## Compliance

Generated content must comply with:

* AGENTS.md rules
* This content specification
* Rubric evaluation criteria

---

## Summary

This content specification acts as a contract between prompts, agents,
and validation, ensuring predictable and high-quality documentation outputs.
